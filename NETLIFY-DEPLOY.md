# LIME FIT — пакет от 24 октября 2026

## Готовый сайт

`LIME-FIT-netlify-site-2026-10-24.zip` содержит готовую сборку: index.html находится в корне. Распакуйте архив и загрузите папку в ручной deploy существующего сайта Netlify. Эта загрузка публикует только статический интерфейс; серверные функции ИИ таким способом не устанавливаются.

## Полный исходный пакет

`LIME-FIT-netlify-source-2026-10-24.zip` содержит исходники восстановления, базовый архив, актуальные файлы программы, тесты, Netlify Functions, конфигурацию Netlify и справочные данные из папки data. node_modules и секреты не включены.

Распакуйте пакет в корень репозитория для Git-сборки Netlify:

- Base directory: пусто (package.json находится в корне этого архива).
- Build command: npm run build.
- Publish directory: dist.
- Functions directory: netlify/functions.
- Node.js: 22, задан в netlify.toml.

Для тренера нужны серверные переменные GROQ_API_KEY, LIME_COACH_PASSWORD (от 16 символов), LIME_SESSION_SECRET (от 32 символов). LIME_GROQ_MODEL необязательна. Секреты задаются в Netlify, не в файлах сайта.

Обновляйте существующий сайт с прежним адресом. Перед обновлением экспортируйте резервную копию через приложение: пользовательские результаты находятся в браузере, а не в этих ZIP. data/initial-data.json — справочные сведения, не резервная копия для импорта.

## Изменения этой сборки

- Плавающий таймер справа вверху, трёхсекундный сигнал, автоматическое скрытие после сигнала.
- Убраны кнопки изменения веса на ±2,5 кг.
- Убраны упражнения на пресс из шаблона программы.
- Тренировки: «Грудь и руки», «Спина и плечи», «Ноги».
- При открытии вкладки «Программа» прежние названия с днями недели обновляются автоматически, пресс исключается из этих дней. Введённые веса, история и начатая тренировка сохраняются.
- Выбранную тренировку можно запустить непосредственно из программы.

Прежние README и docs/AI-SETUP.md содержат исторические сведения. Для структуры этих архивов используйте данный документ. Нативный iOS-проект в пакет не входит.
